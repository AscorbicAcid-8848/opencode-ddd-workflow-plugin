# OpenCode 控制面板真实宿主测试

测试日期：2026-09-07。宿主：本机 OpenCode 1.18.18，Windows 原生终端。

这次实际启动 OpenCode、输入 Slash 命令并操作页面，不是仅调用模拟 SDK。配置、数据和状态使用隔离的 XDG 目录，项目使用 `hmdp01/openspec` 的副本；未更改用户的全局配置或真实业务审核结果。

## 实测发现与修正

1. **插件 active，但命令不出现。** 此版本 keymap 的命令菜单使用 `namespace: "palette"` 和 `slashName`。此前误用了普通命令适配器的 `slash: { name }`，字段虽然通过 TypeScript 检查，却未被宿主筛选器识别。现已修正，并用真实 Keymap 的菜单查询增加回归断言。
2. **操作后页面重新显示“加载中”。** 页面构建读取了响应式 KV，保存偏好触发了整个路由重新构建。页面实例构建改为 `untrack`，内部仍主动刷新内容。
3. **Tab 不切换视图。** 宿主按键系统先于 Renderable 收到 Tab。页面现在注册只在本页面焦点范围内有效的 keymap layer；退出时注销，不覆盖会话和对话框的快捷键。
4. **窄终端摘要及按钮被长文本挤出。** 计数摘要前置，搜索标签截短，完整查询保留在搜索对话框中。
