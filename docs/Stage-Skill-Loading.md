# 阶段专业 Skill 的强制加载

三个工作流共 36 个阿拉伯数字阶段均使用 workflow-profiles 中的 skills 映射。00-request 在 init 时加载；其他业务阶段在 prepare 时从插件自身 skills/<name>/SKILL.md 完整读取并通过 stageCard.professionalSkills 返回。不是只返回 Skill 名称，也不依赖模型额外调用宿主的 skill 工具。

加载发生在阶段状态写入之前。未配置、文件缺失、空文件或越界路径均失败，不降级为无专业指导继续。只加载当前阶段的 Skill，多个 Skill 按配置顺序返回，重复名称去重；罗马数字总结阶段仍由运行时独占。

prepare 在 preparedStage.loadedSkills 记录名称、源路径和内容 SHA-256，便于确认本次准备加载的版本。这里的哈希仅标识指导版本，不引入反复文档哈希检查。正文不修改，阶段边界和人工审批仍由原状态机控制。加载成功证明方法指导已经提供，不证明模型一定正确应用，业务质量仍需验收和评测。

验证包括三个工作流全部阶段的映射及正文一致性、缺失/空/非法路径失败，以及真实 prepare 返回正文并记录加载凭据。没有重新执行用户业务工作流。
